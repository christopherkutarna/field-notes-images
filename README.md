# Field Notes images

The finished sketches that go out in Chris Kutarna's Field Notes emails. This repo is public on purpose: the files
are served from here into the emails (Kit keeps external image links). One file per note: `<note-id>.jpg`.

Written by the Field Notes pipeline (private repo `field-notes`). The drawings are © Chris Kutarna; please ask before reusing them elsewhere.

`pull.html` is a one-line hand-over page. OmniFocus only makes web links tappable, so the Field Notes review task
links to `https://christopherkutarna.github.io/field-notes-images/pull.html?uuid=<Drafts UUID>`, which opens that
draft in Drafts and runs *Pull from Field Notes*. It carries no data of its own.
